# AlphaLens

美股多因子量化研究终端。按研究池比较公司、追溯评分依据，并用同一份历史数据检验策略和组合风险。所有计算均可在本机完成。

## 启动

需要 Python 3.10 或更高版本，以及支持 ES Modules、Web Worker 和 DecompressionStream 的现代浏览器。Python 服务仅使用标准库。

```bash
git clone https://github.com/YutongWu901/AlphaLens.git
cd AlphaLens
python serve.py
```

Windows 也可以双击 **启动 AlphaLens.cmd**。默认打开 http://127.0.0.1:8765/ 。使用 `python serve.py --port 8766` 可更换端口，使用 `--no-auto-refresh` 可固定本次研究的数据版本。持仓、观察列表和权重保存在当前浏览器所在站点的本地存储中。

## 随附数据

快照截至 **2026-11-23 美股收盘**。首页先载入 67 只跨行业股票、4 只 ETF 和 4 条指数。切换标普 500 或纳斯达克 100 时，浏览器按需解压对应数据。两个股票池分别覆盖 503 和 101 个成分证券，去重合计 518 只。此快照中 507 只有匹配的年度财报，509 只有盈利预期记录。不同因子所需字段另行判定。行情历史最早自 2018 年 1 月起，新上市公司从可得日期起算。

| 内容 | 来源和口径 |
| --- | --- |
| 美元收盘价、复权价、成交量、拆股 | Yahoo Finance。复权价用于收益与动量，拆股口径一致的股价和 EPS 用于估值。[历史行情](https://finance.yahoo.com/quote/SPY/history/) |
| 财年收入、利润、资产负债、EPS | SEC EDGAR 原始 10-K 按实际披露日匹配，保留申报编号及原始标签。年度数据更新频率低于季报。[Company Facts API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) |
| 盈利预期 | 记录采集当日同一财年的 GAAP 一致预期及 30 日前的对照值。保留真实采集时间。[分析师预期](https://finance.yahoo.com/quote/AAPL/analysis/) |
| 宏观背景 | FRED 的 DGS2、DGS10 和 VIXCLS 各自显示观测日，当前版本用于描述市场。[美国国债收益率](https://fred.stlouisfed.org/series/DGS10) · [VIX](https://fred.stlouisfed.org/series/VIXCLS) |

## 研究路径

1. **选股与错杀识别**。选择指数、研究样本或自定义池，调整八项因子权重。综合分按可用因子的横截面百分位加权，覆盖权重低于 50% 时显示缺失。错杀页列出距年度高点的回撤、收入变化、净利率变化和 EPS 预期修订。
2. **个股分析**。点击股票行查看因子原值、优势和风险、收盘历史，以及盈利保持不变时的估值回归情景。历史市盈率区间为有效月末观测的第 10 和第 90 百分位。
3. **因子研究与回测**。检验逐期 Spearman Rank IC、相关性、分市场状态及分期稳定性。回测支持持仓数、权重、调仓频率、最低分、单边费用及滑点。前一交易日信号在下一交易日收盘执行，持仓权重随价格漂移，净值与 SPY、QQQ 在同一区间比较。
4. **机器学习**。以时间递增的训练窗研究线性及非线性因子组合，训练时仅使用已经兑现的未来收益标签。界面展示每折训练截止日、测试期系数与样本外比较。
5. **组合与概率**。输入股数与现金，检查行业集中度、个股风险贡献、相关性、Beta、历史 VaR 和尾部平均损失。通过联合区块重采样，对比不同仓位的亏损、目标触及及回撤分布。单股价格目标使用价格收益，组合收益目标使用复权收益。

默认的七股历史研究池在 2023 年已有公开成分依据，研究起点限制为 2024-01-02。样本集中于大型科技公司。标普 500 与纳斯达克 100 的全量扫描使用采集日成分；用这些成分回溯早期业绩会引入幸存者和选择偏差。长期指数策略验证需要完整的历史成分区间、退市证券及退市收益。[冻结股票池依据](https://blog.roundhillinvestments.com/how-to-gain-exposure-to-the-magnificent-7)

## 更新数据

本地服务运行期间，每个工作日美东 17:15 后检查收盘数据。也可在「数据工作台」手动同步。刷新器校验日期并原子替换快照，完整指数扩展与基础数据校验日期和成分一致后才会合并。更新需要访问行情、SEC、FRED 和成分名单网站。SEC 请求可通过环境变量 `SEC_USER_AGENT` 设置实际使用者的联系信息。

```bash
python refresh.py --universe saved
python build_universes.py
```

添加新的自定义股票可执行 `python refresh.py --symbols AAPL,MSFT,BRK-B`。也可使用 `--universe sp500`、`nasdaq100` 或 `all` 下载相应范围。直接运行刷新器后可重新生成两份指数扩展。纯静态部署使用发布时快照；刷新后需重新部署数据文件。

## 验证与复现

```bash
npm test
```

测试使用 Node.js 22.7+，覆盖申报时间边界、收盘后预期与历史信号隔离、下一收盘成交和交易成本、收益漂移、缺价处理、风险贡献、模拟种子复现和价格目标口径。单元测试中的构造序列仅用于验证数学行为。产品页面分析来自随附或新采集的真实数据。

保留 Git 提交、收盘快照、股票池、权重、成本与随机种子可复现研究。每个研究区保留模型口径和 CSV 导出。历史持仓缺少连续可核验价格时，回测会定位并报告证券和日期。例如随附快照中 SNDK 在拆股日 2026-11-20 缺失收盘价，持有该日的策略需补齐数据才能得出完整业绩。盈利预期的观察历史从实际采集开始；最新一致预期不会回填历史日期。模拟概率以选定历史窗口及重采样假设为条件。

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `serve.py`、`refresh.py`、`build_universes.py` | 本地服务、采集校验、指数分片 |
| `dist/data/`、`dist/universe.js` | 日期一致的快照、按需加载 |
| `dist/quant.js` | 可在浏览器和 Node.js 中调用的纯 JavaScript 量化引擎 |
| `dist/research-worker.js`、`dist/research.js` | 后台研究计算、交互式研究界面 |
| `dist/app.js`、`dist/graphics.js`、`dist/screening.js` | 终端导航、行情图、排名和筛查证据 |
